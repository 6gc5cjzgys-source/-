# Phospholipid Bilayer 3D

磷脂双分子层 Three.js / WebGL 交互教学网页。

## GitHub Pages 发布

1. 在 GitHub 新建一个仓库，例如：`phospholipid-bilayer-3d`
2. 把本文件夹中的 `index.html` 和 `.nojekyll` 上传到仓库根目录。
3. 打开 `Settings → Pages`。
4. 在 `Build and deployment` 中设置：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
5. 点击 `Save`。

如果 GitHub 用户名为 `YOURNAME`，仓库名为 `phospholipid-bilayer-3d`，发布地址通常为：

`https://YOURNAME.github.io/phospholipid-bilayer-3d/`

如果仓库直接命名为 `YOURNAME.github.io`，则地址为：

`https://YOURNAME.github.io/`
